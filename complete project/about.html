About This Project

A complete Web Development Internship Project created using HTML, CSS, Bootstrap and JavaScript.

Project Overview

WebHub is a multipurpose web application developed as part of a Web Development Internship. It demonstrates front-end web development concepts using modern technologies.

The project integrates multiple modules into a single website, allowing users to explore weather information, search movies, view a personal portfolio and send messages through a contact form.

The website is fully responsive and works on desktops, tablets and smartphones.

Technologies Used

HTML5

Provides the structure of the website.

CSS3

Used for styling, layouts and animations.

Bootstrap 5

Makes the website responsive and modern.

JavaScript

Provides dynamic features and API integration.
